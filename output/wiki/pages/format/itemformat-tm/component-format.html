Component Format

This feature is only available for 1.21.6+ Paper server users.

Custom Name

component:
  name: '<blue>A good sword'

Item Name

component:
  item-name: '<yellow>Not Bad sword'

Lore

component:
  lore:
    - '<gray>This is really nice!'

Custom Model Data

component:
  custom-model-data:
    float: # Custom Model Data Type
      - '1'
    flag:
      - 'true'
    string:
      - 'Let me just test it!'
    color:
      - '255, 255, 0'
